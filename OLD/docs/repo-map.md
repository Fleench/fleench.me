# Repo Map

This file describes where project files belong.

## Root

- `gen.py` is the active generator.
- `config.yml` controls source/output paths and plugins.
- `bot.py` contains publishing/build automation.
- `nexus.py` is an auxiliary command interface.
- `requirements.txt` lists Python dependencies.

## Source

- `src/*.md` are top-level authored pages.
- `src/blogs/` contains blog Markdown.
- `src/notes/` contains note Markdown.
- `src/templates/` contains `*.html.temp` templates.
- `src/templates/mobile/` contains mobile-specific templates.
- `src/elements/` contains reusable `.element` includes and dynamic `.py` elements.
- `src/css/` contains stylesheet assets.
- `src/js/` contains browser JavaScript assets.
- `src/theme/`, CSS, JS, and images are copied as static assets.

Markdown pages should stay in their current page/blog/note locations.

## Generated Output

- `dist/` is generated by the build and ignored by Git.
- Do not edit files in `dist/`; edit `src/`, templates, elements, or scripts instead.

## Support Areas

- `scripts/` contains plugins and helper commands.
- `tests/` contains automated checks.
- `docs/plans/` contains planning notes and future ideas.
- `docs/bots/` contains bot-related notes.
- `docs/experiments/` contains scratch or experimental notes.
- `archive/gen-history/` contains old generator snapshots.
- `archive/template-backups/` contains old template backups.
