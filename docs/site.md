# Site Architecture (site.md)

The site is structured with a modular approach, separating content (Markdown) from layout (Templates) and styles (CSS).

## Layout & Templates
- Templates are located in `src/` (mostly `*.html.temp` files).
- **Core Layouts**: `page.html.temp` serves as the primary base.
- **Mobile Templates**: Found in `src/mobile/`, specific to mobile rendering logic.

## Styling
- **Global Styles**: `style.css` (primary) and `style-grid.css` (layout structure).
- **Dark Mode**: `dark.css` provides alternate styling, toggled via `theme-mode.js`.
- **Mobile Styles**: `mobile.css` for specialized mobile display overrides.

## Elements
- Content is organized into blocks within Markdown files using `---` delimiters, which map to CSS class and ID containers dynamically generated by `gen.py`.
