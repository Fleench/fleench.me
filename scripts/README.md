# Scripts

Scripts are build helpers, plugins, and operational tools.

- `mobile.py` builds mobile-specific output.
- `rss_plugin.py` writes RSS feeds.
- `webmentions.py` queues and publishes webmentions.
- `create_page.py` creates new content pages.
- `build_l1.py` and `build_l2.py` are build automation helpers.
- `setup_gemini_mcp.sh` is local setup tooling.

Build plugins are loaded from `config.yml`.
